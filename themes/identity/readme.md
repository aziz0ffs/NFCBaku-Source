# Identity — Beyond the Card

* Theme Name: Identity — Beyond the Card
* Theme Version: 1.0
* Theme Author: NFC Baku
* Theme License: AGPL-3.0
* Source code: https://github.com/aziz0ffs/NFCBaku-Source

Selectable LinkStack theme. Uses the current profile name, description, avatar,
public links and optional UserData `identity` fields (location, profession, quote,
phone, email). No account identifiers or personal content are bundled.

Rebuild: `cd theme-src/identity && npm ci && npm run build`.
React/ReactDOM, GSAP, Lucide, Vite and Fontsource retain their upstream licenses;
font licenses and third-party notices accompany this theme's source.
